# Editor UI Scaling
scale editor ui

if ur a dev check github readme for info as to how ui scaling works

*btw this mod also allows u to bypass button rows/buttons per row, bypass at ur own risk i dont guarantee ui will look good*

## Supported mods
these mods should have support out of the box

- **BetterEdit** - hjfod
- **Tinker** - alpha (some issues if u scale ui outside of the range {0.4, 1.0} but like y would u do that)
- **Named Editor Layers** - razoom
- **Object Groups** - razoom
- **Start Position Viewer** - d050

these mods impl support themselves

- **SillyEdit** (whenever thats released) - fei
- **Trigger ID Search** - fei

most other mods should prolly b supported assuming they use node ids, otherwise submit a bug report or smth if u want
