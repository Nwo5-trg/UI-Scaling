# Editor UI Scaling
scale editor ui

if ur a dev check github readme for info as to how ui scaling works

*btw this mod also allows u to bypass button rows/buttons per row, bypass at ur own risk i dont guarantee ui will look good*

## Tinker
if any ui setting is changed in tinker, editor ui scaling will b set to match tinkers current settings, this is intentional but i might add a setting in the future if u dont want this behaviour (on settings change for this mod or editor reload, this mods settings will take precedence again)

also some issues if u scale ui outside of the range {0.4, 1.0} but like y would u do that

## Supported mods
